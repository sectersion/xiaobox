# XIAOBOX Code Workspace

Welcome to the XIAOBOX coding environment! This is a sandboxed VS Code server running in your browser.

## Getting Started

1. **Explore the files** in the workspace
2. **Try editing** the example files
3. **Run code** using the terminal (Ctrl + `)
4. **Install extensions** from the Extensions panel

## Example Files

- `hello.py` - Python hello world
- `hello.js` - JavaScript hello world
- `hello.html` - Basic HTML page
- `styles.css` - CSS styling

## Tips

- Your work is temporary and will reset when you close the tab
- Use the integrated terminal to run commands
- Install any VS Code extensions you need
- Have fun coding!
